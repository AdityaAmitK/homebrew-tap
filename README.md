# Homebrew tap

Homebrew formulae and casks by Aditya Kinjawadekar.

```sh
brew install adityaamitk/tap/kestrl          # Kestrl CLI
brew trust adityaamitk/tap                    # once, required for third-party casks
brew install --cask adityaamitk/tap/kestrl   # Kestrl macOS app (Apple Silicon)
```

Kestrl: https://kestrl.adityakinjawadekar.com
